| Type       |  Size | Declaration |
| ---------- | ----- | ---------- |
| `bool`     |1 byte | `bool x = true`|
| `char`     |1 byte | `char x = 'H'`|
| `short`    |2 bytes| `short x = 3` |
| `int`      |4 bytes| `int x = 3` |
| `float`    |4 bytes| `float x = 3.1` |
| `long long`|8 bytes| `long long x = 3` |
| `double`   |8 bytes| `double x = 3.1` |
